# 工作台布局

- 页面缩略图栏顶部可收起或展开；收起后保留 36px 展开入口，图片自动使用释放的空间。浏览器会记住折叠偏好，存储不可用时仍可在当前页面切换。
- 顶部“工作台”按钮返回 `/workspace`，端子排列表、详情和识别页均可使用。现有离页保存保护继续生效。
- 图片顶部保留紧凑分页和操作按钮，文件信息独立显示；长文件名省略，悬停查看全文。面板变窄时按钮自动换行，缩放组保持完整。
- 收起页面栏不会切换页码、重置缩放或结束编辑。已有 API 和 OCR 数据格式不变。

验证：`npm test -- src/workspaceLayout.test.ts`；`npm run build`。

## 表格工具栏与配色

工具栏采用 28px 高、12px 字号的轻量按钮。撤销、重做使用图标，悬停可查看名称；填充、编号和放大保留文字。操作帮助默认收起，可点击或用键盘展开。

空闲时不显示零行保存状态；保存时显示蓝色计数，失败或冲突显示橙色计数。保存失败可重试，版本冲突仍需核对后逐项重试。

Tabulator 默认灰色主题在此表格内覆盖为浅灰绿色表头、白色与浅灰绿色交替行和淡网格线；保留选区与当前图片关联行高亮。

验证：`npm test -- src/ocrGridToolbar.test.ts`。

## 端子业务记录与识别证据分离

有端子检测结果的页面使用独立 `terminal_documents` 表，以页为单位保存端子记录及版本号。每个记录具有稳定 ID、端子点 ID、识别来源 ID、端子号、最终线号、备注、人工确认状态和人工修改标志。列表仅展示 OCR 识别证据；表格补录不会创建图片框或列表项。

表格编辑、粘贴、清空、填充和编号整批保存，仅修改业务值。撤销/重做覆盖整次批量操作；切换列表保留本次会话历史。保存失败保留整批输入，可重试或明确放弃后重新加载。版本冲突时不覆盖服务器值。纯人工记录撤销恢复空行，不产生空 OCR 项。

表格工具栏提供“删除识别结果”：先勾选表格行，确认后将其关联的有效 OCR 来源标为已删除，与列表删除使用同一接口。所选线号从列表与表格同步消失；有端子点的行保留端子号并按剩余线号重新匹配，未匹配的额外线号行移除。即使线号对应的表格值曾被人工编辑，该线号删除后也不保留为业务值。没有 OCR 来源的端子空行或纯人工行不参与删除。删除后可用页面底部的“撤销上一次结果操作”恢复。表格编辑单元格仍用于清空业务值，二者含义不同。`src/businessDeletion.test.ts` 验证所选业务行到有效 OCR 来源的映射，`src/ocrGridToolbar.test.ts` 验证按钮入口与禁用状态。

列表纠正后，尚未人工编辑或确认的表格值跟随识别来源；人工值保留并提示来源变化，可明确采用识别值。线号被删除或标记误检后，关联的线号从表格中移除；端子行按当前有效线号重新匹配。

表格“纠正来源文字”按来源 ID 定位识别框，展示局部图片、原始值、当前纠正值和业务最终值。人工处理的记录打开来源纠正时默认勾选同步，用户可取消以仅纠正来源；同步后重新待确认。来源纠正与同步业务值在同一事务保存，撤销时也一并回退，OCR 原始文字及纠正历史保留。无来源的人工补录行不可纠正来源。

表格点击高亮端子点，来源纠正高亮 OCR 框；行序号不承担关联身份。表格模式导出与左右侧合并读取独立业务记录；列表模式导出保留 OCR 结果。新增加的端子点按当前线号坐标匹配，匹配不到时生成空记录；被移除端子点的业务记录保留并提示，不参与有效表格行和端子导出。

### 接口与部署

新增 GET/PUT `/api/v1/ocr/jobs/{job_id}/pages/{page_no}/terminal-document`，已有接口保留。PUT 包含页版本、完整记录快照、可选来源纠正及同步记录 ID，原子验证两个版本。撤销仅保证当前页面会话内有效，不覆盖其他会话的版本变化。

PostgreSQL 部署需执行 `alembic upgrade head`，新增迁移 `b2_terminal_documents`；SQLite 本地数据库自动新增表。首次读取按现有配对和已保存字段初始化，保留既有人工值。旧端子补录 OCR 记录不物理删除，按绑定迁移为业务值并从工作台列表隐藏，避免丢失历史。旧表格对 OCR 原文产生的纠正历史保留，无法自动判断其原始业务意图，需人工核对。

验证：前端类型检查、Vitest，后端 `test_terminal_document_isolates_values_and_atomically_corrects_source`，以及 `npm run test:business` 浏览器测试。


### 全量编号展示与定位

表格保留全部有效 OCR 编号，包括未匹配到端子点的记录，另保留有端子点但无识别文字的空行。每次读取业务文档时，按当前端子点及线号框的位置重新匹配未人工修改的行；新框若比原线号更接近端子点，可取代旧关联，旧线号转为端子号为空的待核对行。已有未匹配行在新增端子点或移动检测框后也能进入对应端子行。人工编辑或确认过的业务行在来源有效时保留其值和来源关联，避免自动刷新覆盖人工处理结果；其占用的来源不会在另一行重复显示。删除或标记误检的来源及其对应业务线号一并移除，即使业务值曾被人工编辑。业务导出和左右侧合并读取采用相同的重匹配结果；未匹配记录按稳定来源 ID 保存。点击未匹配行定位来源识别框，有端子点的行定位端子点。当前选中端子点使用橙色 `#fa8c16`，普通点仍为蓝色。

回归验证：`backend/tests/test_terminal_document_records.py` 覆盖新框取代旧匹配、未匹配来源进入新端子点、移动检测框、人工值保护和失效自动来源移除；`backend/tests/test_api.py::test_manually_added_ocr_box_is_visible_in_existing_terminal_document` 覆盖真实保存、表格读取和导出。

界面在保存新增、移动或删除检测框后会刷新该页 OCR 列表并重新加载端子业务表格；端子点和线号几何变化均触发重载。如果刷新时表格正执行上一次加载或保存，新的加载请求排队到当前操作结束，避免漏掉本次变化。


### 携带来源的复制与剪切

在同页表格线缆编号列选择单个或连续多个单元格，Ctrl+C 复制、Ctrl+X 标记剪切，再选目标起点 Ctrl+V。内部剪贴板携带文字与识别来源，目标“纠正来源文字”随关联更新；端子点和端子号固定。剪切仅在粘贴成功时清空源编号及来源，支持重叠范围上移；整批保存、撤销和重做包含来源关联。目标人工确认重置为待确认。来源发生变化时要求重新剪切。向下填充同样携带来源。

外部 Excel 或跨页粘贴只有文字，不伪造来源，目标旧来源会清除；单元格内编辑文本使用浏览器文本剪贴板规则。复制允许多个端子引用同一识别框，不复制或移动图片框本身。


表格行同时具有线缆编号与来源识别框时，点击行同时选中端子点（橙色）和来源框（红色）。空编号行仅定位端子点，无端子点的识别行仅定位来源框，清除上一行不适用的高亮。来源纠正弹窗每次打开默认勾选“同时修改当前端子的最终线缆编号”，可取消勾选。
