# 端子排识别流程（当前版本）

入口：端子排任务页面 → 识别向导，或单侧任务中的识别入口。

1. 上传图片并框选一个或多个文字识别区域。
2. 确认左侧或右侧。
3. 整图检测端子孔，按需添加、删除或移动孔位，再确认骨架。
4. 点击起始端子。
5. 确认从上到下的编排、起始编号和命名规律。
6. 选择光照处理（原图 / 全局 HE / CLAHE），再点击“开始文字识别”。在全部用户文字选区内执行文字 OCR，随后按原有逻辑自动匹配端子点和文字结果，在结果页面继续校正。

第五步确认后即可识别，不再生成文字位置预览，也不需要识别前逐孔确认对应关系。文字识别范围独立于端子孔数量；孔位漏检时，选区内文字依然全部识别，未匹配到孔位的文字保留在结果中供后续修正。最终任务复用已确认骨架，不重复运行 YOLOX。

修改前序配置会撤销后续确认。草稿地址中的 workflow 参数用于刷新恢复；旧草稿即便包含第六步候选与对应关系，新提交也忽略这些数据并按完整选区识别。已有运行任务仍使用其原执行快照。

识别向导页面提供纵向滚动条。图片按宽度显示完整高度，可上下滚动查看；右侧操作区随页面滚动保持可见。

接口保持兼容：/api/v1/terminal-workflows 创建和查询草稿，configuration 更新配置，confirmations 确认步骤，skeleton-detections 生成整图骨架，recognitions 提交识别。写请求携带 base_revision。历史 position-previews 接口保留，但当前页面不调用，也不作为识别前置条件。新执行快照使用 matching_mode=auto，历史快照继续兼容。

测试覆盖：前五步提交校验、无预览直接识别、完整选区 OCR、端子漏检时保留未匹配文字、历史端子匹配与结果校正回归。

## 任务内左右侧流程

填写端子排任务名称并创建后，直接进入左侧识别流程。顶部固定显示任务名称与“左侧 / 右侧 / 合并结果”三个标签。流程、执行进度和结果校正均在对应侧内部显示，内容区独立纵向滚动。

任务内使用 /terminal-tasks/:terminalId/:side，重新识别使用 /:side/workflow?new=1，结果地址继续兼容 /:side/:jobId。第二步方向固定为所属侧，仍需用户确认。切换左右侧恢复各侧后端草稿，未完成的新草稿优先恢复。识别期间仍可查看另一侧；提交和保存请求未完成时阻止切换。方向与编排表单在离开时保存。

新增 GET /api/v1/terminal-tasks/{id}/sides/{side}/workflow 查询当前流程；POST /sides/{side}/workflows 使用 file_id 创建流程，replace=true 明确开始新识别。草稿保存 terminal_task_id 和 task_side，历史尝试继续保留。基于现有 objects 表保存当前流程索引，不新增数据库迁移。

后台识别成功后自动关联到所属侧，不依赖浏览器打开。替换前检查当前流程及原关联；冲突或部分失败保留待采用结果，原结果继续有效。结果页仍支持“采用当前结果”。任务删除后禁止继续访问、创建或提交其流程。已有接口和历史独立流程保持兼容。

## 识别工作台视觉与工具

上传入口改为白色卡片和拖放区域，可点击“选择图片”或拖入文件，沿用图片类型与 200 MB 限制。任务所属侧以小标签显示，加载草稿期间显示准备状态。

流程使用紧凑步骤导航，左侧图片工作区、右侧操作卡片。已完成步骤可返回，未开放步骤保持禁用。每步使用具体确认文案。图片工作区支持缩放（50%–250%）、适应宽度及独立长图滚动；任务外壳与当前流程仍保留纵向滚动。

骨架工具栏：选择、添加端子、删除端子、撤销、生成骨架/重新检测。点击添加工具后点击图片空白处新增，删除工具下点击孔位删除，悬停显示红色提示；选择工具下可在右侧编辑孔位坐标。撤销记录最近 20 次本页面成功保存的孔位编辑，刷新或重新检测后清空。起始端子显示橙色标记。

UI 验证命令：node tests/workflow-ui/smoke.cjs。使用模拟数据验证上传空态、非图片拦截、孔位添加/删除/撤销、缩放与长图滚动；截图输出 .codex-output/workflow-ui/upload.png 和 skeleton.png。真实模型效果不属于该页面测试范围。

## 端子孔字母编号

第五步“端子孔编号方式”支持数字顺序与字母顺序，独立于线号管命名规律。字母编号可设置起始值（1–10 位英文字母，如 A、Z、AA）与大小写，按 A…Z、AA…AZ、BA…ZZ、AAA 的顺序递增；从选定起始孔位开始，仍按图片从上到下编排。编号预览、图片标注、执行快照与最终结果采用同一规则。纯字母的合并结果按该顺序排列；左右编号精确相同才自动合并，大小写不同不视为同号。

新配置字段 numbering_mode（numeric/alpha）、letter_start、letter_case（upper/lower）为可选项，历史草稿默认数字顺序。数字模式继续使用原 start 字段。字母模式不改变线号管文字的识别和命名校验。

端子排任务上传图片后，预览弹窗默认勾选“框选模式”，可以直接拖动添加文字区域。关闭后重新打开仍默认勾选；已有选区继续保留。普通 OCR 工作台的上传预览保持原有默认行为。


## 可调布局与更换图片

原图与右侧操作卡片之间增加可拖动分隔条，可左右拖动调整宽度，双击恢复默认。分隔条可使用 Tab 聚焦，以左右方向键微调，Home 恢复默认。保留图片缩放和上下滚动。

识别前各步骤提供“更换图片”。新图片预览默认进入框选模式，不沿用旧图选区。取消预览保留当前流程；保存新图与选区后，创建当前侧的新草稿，回到第一步，重置骨架、起点、编号与编辑撤销记录。已采用的识别结果仍保留到新识别成功。执行中的流程不可通过此入口换图。

任务内创建流程接口新增可选 regions 参数，在同一事务中校验并保存初始选区，再切换当前草稿索引；无效选区不会替换旧草稿。省略该参数的旧调用保持兼容。


## 表格编号一致性修复

表格自动行优先使用第五步确认的孔位编号（含字母及自定义数字起点），不再被 OCR 行上未人工编辑的数字序号覆盖。前端旧表格路径也读取孔位的 terminal_number，空文字端子行同样显示配置编号。人工编辑过的端子号继续保留。

历史识别任务若已保存执行快照但页面孔位缺少编号，读取页面、业务表格及已有业务记录的合并/导出时，按快照恢复原孔位的编号。未人工修改的旧业务数字行会在表格刷新时重新对齐；不会重新运行 OCR，不覆盖人工确认或编辑记录。无流程快照的旧任务继续使用原数字回退逻辑。

骨架流程中的普通端子孔使用实心亮蓝色（#1677ff），配白色描边及深蓝外圈，提升灰色设备原图上的可见性。选中孔位使用绿色，起始孔位使用橙色，删除悬停使用红色；底部图例同步显示。结果页原有蓝色端子点继续保持一致。


## 端子孔编号前缀与线号管前缀

第五步增加可选“端子孔编号前缀”，对应 ordering.number_prefix，默认空字符串、最多 40 字符单行文本。该字段直接参与孔位编号生成：数字模式 XT-1、XT-2；字母模式 XT-A、XT-B 或 XT-Z、XT-AA。大小写选项只影响递增字母，不改动前缀。预览、图片标注、结果业务表、历史快照恢复及导出使用同一编号。

第五步“线号管命名规律”须选择 Auto、现有柜、临时柜、新柜之一，未选择不能确认编排。所选规则写入本次识别任务的 `options.numbering_scheme`，识别时仅在对应编号库与格式规则内校验；Auto 同时使用三套规则，已知编号精确命中优先于格式规则，同可信度时按现有柜、临时柜、新柜顺序选择。未命中时沿用人工核对流程，原有字符候选、非法字符清理及端子匹配逻辑不变。重新识别沿用原任务的命名规律，普通非向导 OCR 任务沿用原校验逻辑。历史草稿中的旧命名值在页面恢复时显示为 Auto。

线号管命名规律独立于 `number_prefix`。编号前缀只改变端子孔编号，不改动 OCR 原始文字。


## 表格单元格局部编辑与列表关系

端子排结果表格的端子号、线缆编号是独立业务值，直接编辑不会修改 OCR 列表文字。需修改列表中的识别来源时，使用表格中的“纠正来源文字”功能。结果删除等明确的同步操作另行处理。

双击单元格进入编辑后不再自动全选，光标默认在末尾。可点击文字定位光标，使用方向键、Home/End、Shift 选择局部文字并插入或替换；Ctrl+A 可全选，Enter/Tab 提交并导航，Escape 放弃编辑。输入框内鼠标和键盘事件不会触发表格的区域选择或导航。

浏览器回归 tests/business/smoke.cjs 覆盖局部替换、鼠标光标、全选、取消、提交与撤销，并验证表格修改不影响 OCR 列表及来源纠正的同步行为。


## 表格编辑同步 OCR 列表（当前行为）

直接编辑端子号或线缆编号时，按稳定 sourceResultId 同步关联 OCR 记录。端子号更新列表的端子号标签；线缆编号保存为来源纠正值，保留原始模型文字。框坐标、端子点和关联 ID 不改变。

无有效来源的行只保存表格，并提示未同步；共用来源时弹窗选择“只改表格”或“同时修改来源”。后者同步共用来源行的对应字段；同一批次对同一来源填写冲突值时拒绝保存。粘贴、剪切和来源移动仍使用原有规则。

新增 POST /ocr/jobs/{job}/pages/{page}/terminal-document/sync，原接口保持兼容。新接口校验文档版本、OCR 文字版本、编号版本、页面归属和共用来源确认，事务内保存表格与来源。编辑、撤销、重做均可在一次请求中处理多个来源，失败保留整批输入，不部分提交。撤销使用原表格和来源快照，来源失效或版本冲突时要求重新核对。

验证：tests/test_terminal_document_sync.py；src/businessSourceSync.test.ts；tests/business/smoke.cjs（自动同步、编号标签、无来源、共用来源两种选择、联合撤销、原来源纠正和剪贴板行为）。


## 光照处理选项恢复（2026-11-03）

向导第 6/6 步与普通工作台（识别模型旁）均可选择“原图 / 全局 HE / CLAHE”，分别对应 `none`、`he`、`clahe`。默认保持原图。原图不做光照增强；全局 HE 均衡整体亮度；CLAHE 增强局部对比度。

向导通过已有 `configuration` 接口的 `changes.illumination` 保存选择，沿用 `base_revision` 校验，刷新或切换左右侧会恢复各自草稿的选择。修改光照不撤销前五步确认，也不重算骨架；保存失败保留服务器已保存的选择。旧草稿缺少该字段时按原图处理。最终识别任务的 `options.illumination` 和流程执行快照均保存本次模式。

工作台的新文件整图识别、上传选区识别、历史任务重新识别、结果页区域识别均传递当前选择。打开历史任务时显示任务实际记录的模式。保存或识别执行期间禁用相关选择，已提交任务的参数不受后续选择影响。

回归验证：`npm test`、`npm run build`；后端 `python -m pytest tests/test_workflow_illumination.py tests/test_ocr_illumination.py tests/test_ocr_engine.py tests/test_ocr_adapter.py tests/test_api.py`；浏览器 `node tests/illumination/smoke.cjs`（先启动 Vite，默认端口 15176）。

## 端子排结果页的流程边界

端子排任务内的结果页使用专用操作栏，只读展示原文件，提供光照处理与“按已确认配置重新识别”。隐藏普通工作台的文件上传、替换、模型切换和独立区域识别入口；相关事件处理也拒绝在端子排模式下创建通用任务。更换图片仍从顶部“重新识别”进入当前侧标准流程。

新增 POST /terminal-tasks/{task_id}/sides/{side}/enhancement-reruns，参数 source_job_id、illumination。服务端核对用户、任务和侧别，复制已完成任务的确认快照，保留完整选区、人工骨架、起始端子与编号前缀/字母规则，仅替换光照方式并创建新尝试。沿用确认骨架而不重新运行端子检测。缺少完整快照的历史结果拒绝直接增强重识别，需回到标准流程。新结果完成后按原采用冲突规则关联，旧结果保留。

普通工作台继续使用原有上传与重新识别行为。


## 原图与区域图片视图

区域 OCR 任务保留原上传文件，新增每个区域的裁剪图和缩略图，默认显示原图。左侧“识别区域”导航可切换原图和各区域；区域不是新页面，不改变页码或结果归属。原图显示区域边界。用户点击缩略图切换视图。保存检测框后按区域 ID 保留当前视图，区域不可用时回到原图。选中结果只改变高亮。

区域图暂不开放端子点编辑：入口隐藏，新增/拖动事件被拦截；需切回原图编辑。区域内孔位仅作只读展示。文字框查看与编辑继续支持，保存前还原为原图坐标；跨越区域边界的框需要手动切回原图编辑，避免裁切造成几何失真。存在未保存几何修改或端子点编辑时，阻止切换视图。

新增受权限保护的 GET /ocr/jobs/{job}/pages/{page}/region-images 元数据接口，及 /{region_id}/content 图片接口（thumbnail=true 获取缩略图）。裁剪边界 floor/ceil 并限制在原图内，实际整数边界返回前端。派生 PNG 按原图版本和裁剪范围缓存，原文件不改动；失败区域可刷新重试，并保留原图回退。图片 blob URL 随页面释放。

原有识别结果、端子骨架、起始端子、编号及保存接口保持原图坐标。列表按当前视图筛选，优先使用来源区域 ID，缺少来源时按坐标判断。表格继续展示整图结果。

验证：tests/test_region_images.py、src/regionImageView.test.ts、src/api/ocr.test.ts、node tests/region-view/smoke.cjs。浏览器测试使用模拟图片验证区域默认显示、原图切换、端子点只读、编辑切换保护和结果定位。
