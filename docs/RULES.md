# 长期稳定规则

本文件是项目的最小必读规范。其他文档只描述各领域设计，不重复以下规则。

## 技术与变更

- 系统是工业端子排 OCR 推理与人工复核系统，不包含模型训练、自动标注或自动回训。
- 前端：Vue 3、TypeScript、Ant Design Vue、Konva。
- 后端：Python 3.11、FastAPI、REST API。
- 不修改已有接口；新增功能必须添加测试并更新对应文档。
- 公共 API 基础路径为 `/api/v1`，JSON 字段使用 `snake_case`。

## 通用数据契约

- ID 使用字符串形式 UUID/UUIDv7。
- 时间使用 UTC ISO 8601，例如 `2026-07-16T03:25:14Z`。
- PDF 页码从 1 开始。
- OCR 置信度字段名为 `confidence`，类型为 0 到 1 的 number。
- OCR 原始文字字段名为 `text`，类型为 string，写入后不可覆盖。
- OCR 包围框固定为 `bbox: [x1,y1,x2,y2]`，不得改为 `{x,y,width,height}`。
- 坐标原点为标准页面图左上角，x 向右、y 向下，单位为像素。
- BBox 必须满足 `0 <= x1 <= x2 <= width_px`、`0 <= y1 <= y2 <= height_px`。
- 后端生成的标准页面图是 OCR、Konva 和原位布局的唯一坐标基准；不得混用 PDF point、原图或缩放后画布坐标。

## 数据所有权与审计

- PostgreSQL 是业务事实来源；Redis 不保存唯一业务数据。
- 模型版本和推理参数必须随任务固化，保证结果可复现。
- 模型原始结果不可变；人工纠正作为独立修订保存，留言独立保存。
- 纠正使用 `base_revision` 乐观并发控制，冲突返回 HTTP 409，不得静默覆盖。
- 撤销纠正通过新增修订实现，不物理删除历史。
- 文件、任务和留言默认逻辑删除；关键操作必须记录操作人和服务端时间。
- 用户、作者、角色和权限来自服务端身份系统，客户端不得伪造。
- 租户数据必须隔离；对象存储桶不得公开。

## API 行为

- 成功响应：`{"data": ..., "request_id": "..."}`。
- 错误响应：`{"error":{"code":"...","message":"...","details":{}},"request_id":"..."}`。
- 创建类接口支持 `Idempotency-Key`；相同键和相同请求返回原结果，请求体不同返回 409。
- 列表默认使用游标分页；任务列表首期允许 page/page_size。
- SSE 仅用于实时体验，任务详情接口始终是状态事实来源，断线后必须可轮询恢复。
- 签名 URL 短期有效，不得持久化到数据库或 localStorage。

## 安全与日志

- 上传文件是不可信输入：校验文件签名、真实 MIME、大小、页数、像素、哈希和资源消耗。
- PDF 处理应隔离并设置超时；文件下载必须先做业务权限校验。
- 日志不得记录 OCR 正文、访问令牌、完整签名 URL 或敏感文件内容。
- 留言按纯文本保存和输出，限制长度并转义展示。
