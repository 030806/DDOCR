# UI 与交互需求

## 1. 页面与组件

```text
App.vue
├─ AppHeader.vue
│  └─ UserMenu.vue
│     ├─ ProfileDrawer.vue
│     └─ PasswordModal.vue
├─ RouterView
│  ├─ WorkspaceView.vue
│  │  ├─ UploadPanel.vue
│  │  ├─ DocumentViewer.vue
│  │  │  └─ BBoxLayer.vue
│  │  ├─ OCRResultPanel.vue
│  │  │  └─ OcrLayoutView.vue
│  │  ├─ CorrectionModal.vue
│  │  └─ CommentDrawer.vue
│  └─ TaskHistoryView.vue
└─ SettingsDrawer.vue
```

- `/workspace`：默认 OCR 工作台。
- `/workspace/:taskId`：加载历史任务并继续复核。
- `/tasks`：任务历史列表。

## 2. 工作台

- 用户选择 PDF/图片和 OCR 模型后创建任务。
- 展示上传、排队、执行阶段、精确进度和错误。
- PDF 支持页码导航；切页后只显示当前页结果。
- 文档区和结果区之间可水平拖拽；文档区最小 400px，结果区最小 300px，两侧独立滚动。
- 文档使用 Konva 独立 BBox 图层；点击框和点击结果必须双向选中同一 result ID。
- BBox 使用页面标准图坐标，渲染时按实际显示比例缩放。
- 结果支持搜索和低置信度筛选。
- 结果支持“列表”和“原位布局”两种模式，共用选中、筛选、纠正和留言状态。
- 原位布局不显示原图，将最终文字按 BBox 映射到等比例独立画布；筛选只控制可见性，不重新排列。
- 切换页面时保留结果展示模式；缩放、分割面板等行为不得破坏框选和定位。

## 3. 结果显示

- 每项展示模型原文、最终文字、置信度和必要的复核状态。
- 最终文字为 `display_text`；无纠正时等于模型原文。
- 置信度可按用户设置隐藏；低置信度阈值可配置。
- 单页结果默认完整加载，保证 Konva 不漏框。
- 页面图签名 URL 过期时重新请求页面数据，不永久缓存 URL。

## 4. 人工纠正与留言

- 结果项可打开纠正弹窗，输入上限 500 字符。
- 提交纠正时携带当前 `base_revision`；409 时展示服务端最新文本和版本，提示用户比较后重试。
- 纠正成功后立即更新最终文字、修订版本和复核计数，模型原文保持不变。
- 结果项可打开留言抽屉；留言输入上限 300 字符。
- 支持留言查询、新增，以及本人留言的编辑和删除。
- 显示服务端返回的作者和 ISO 时间，按用户时区格式化；不使用仅含时分的字符串作为数据。

## 5. 任务历史

- 显示任务名、文件、模型及版本、时间、页数、完成/失败页、状态、审核状态、进度、耗时、结果数、复核数和创建人。
- 支持任务名/文件名搜索、状态筛选、创建时间排序和分页。
- 支持查看、继续复核、导出、取消、重试和带确认的逻辑删除。
- OCR `partial_success` 与 `needs_review` 必须以不同视觉语义展示。

## 6. Excel 导出

- 当前页完整数据已加载时可由前端导出。
- 精简模式包含编号和最终识别结果。
- 完整模式包含模型原文、人工纠正、最终结果和留言。
- 多条留言每条独立占一行。
- 默认导出完整当前页，不受搜索或低置信度筛选影响；只有用户明确选择时才导出筛选结果。
- 大文档或全任务导出使用后端异步导出并展示状态和短期下载入口。

## 7. 用户与设置

- 用户菜单显示真实用户资料、角色、部门和脱敏联系方式。
- 密码修改仅在本地身份模式使用；OIDC 模式跳转身份提供商。
- 退出必须结束真实会话或刷新令牌。
- 设置项：默认模型、低置信度阈值、默认结果视图、是否显示置信度、默认导出模式、页面缩放。
- 无跨设备需求时继续保存到 `ddocr.settings.v1`；需要同步时使用用户偏好 API。
