# 端子与线号人工匹配

端子任务的表格初始按纵向位置分别排列端子号和线号。同一行仅表示并排展示，不表示关联。已人工确认的匹配行显示“已匹配”；剩余行显示“仅并排”。列表始终保留真实 OCR 结果，标明“待匹配”或已关联的端子。

向导识别完成时可能给 OCR 结果写入 `terminal_point_id`：它表示该文本框落入某个已确认的线号位置，是流程提供的定位线索。该字段不能单独证明线号与端子已经由用户确认匹配。真实 OCR 文字即使带有此字段，也仍作为待匹配线号展示；空文字的端子占位记录不作为线号展示。

在原图工具栏选择“连线匹配”，依次点击端子点和线号检测框即可预览连线。一个端子点与一个线号框最多各参与一条连线。重新连接已有线号会在预览中解除旧关系；“撤销上一条”和“解除选中关联”可调整本次预览。“保存并退出”按整页提交；“取消”丢弃未保存的修改。退出后可用“显示匹配关系”查看已保存连线。

表格中剪切并移动线号来源会转移关联。普通复制、向下填充和直接修改文字只修改业务值，不生成新的来源关联。后续合并和导出不得将“仅并排”的两个单元格视为同一端子线号对。

新增 `POST /ocr/jobs/{job_id}/pages/{page_no}/terminal-links`，请求包含 `base_revision` 和 `links`（端子点 ID 到 OCR 结果 ID 的映射）。服务端以修订号保护整页保存，要求端子点和 OCR 结果属于当前页且来源唯一。旧的 `terminal-document` 接口保持不变。

识别结果允许大小写字母，输出保留模型或人工输入的大小写。整图 OCR 片段合并的横向距离限制比局部 ROI 更严格，防止跨越端子排合并左右文字。
